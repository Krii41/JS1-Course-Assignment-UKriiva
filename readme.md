# Rainy Days

Rainy Days is an online shop for men's and women's rain jackets.
The project is built with HTML, CSS, and JavaScript and integrates the Noroff API 
to display product data dynamically.

## View Online

- Live site:  https://krii41.github.io/JS1-Course-Assignment-UKriiva/
- GitHub repo: https://github.com/Krii41/JS1-Course-Assignment-UKriiva

## Installation

```bash
git clone https://github.com/Krii41/JS1-Course-Assignment-UKriiva.git
cd JS1-Course-Assignment-UKriiva
```
Open `index.html` in your browser.

## Technologies

- HTML5
- CSS3
- JavaScript
- Noroff API

## Features

- Responsive website
- Product data fetched from the Noroff API
- Product detail pages
- Shopping cart functionality
- Checkout page
- User profile page
- Mobile-friendly layout

## Usage

Browse products, view product details, add items to cart, and complete the checkout process.
